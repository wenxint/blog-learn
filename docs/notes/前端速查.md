## 一、新增一个页面的四个步骤

以「友链页」为例：

**① 写页面** `src/views/Links.vue`

```vue
<script setup>
import { onMounted, ref } from 'vue'
import request from '../api/request'

const links = ref([])
const loading = ref(true)

onMounted(async () => {
  try {
    // 返回的已经是 data 部分（拦截器剥过壳）
    const data = await request.get('/links')
    links.value = data.list || []
  } finally {
    loading.value = false   // ❗ 一定要在 finally 里关 loading，否则报错后一直转圈
  }
})
</script>

<template>
  <div class="container">
    <el-skeleton v-if="loading" :rows="3" animated />
    <div v-else-if="links.length === 0">还没有友链</div>
    <div v-else class="list">
      <a v-for="l in links" :key="l.id" :href="l.url">{{ l.name }}</a>
    </div>
  </div>
</template>
```

**② 注册路由** `src/router/index.js`（放在 DefaultLayout 的 children 里，自动有页头页脚）

```js
{ path: 'links', name: 'links', component: () => import('../views/Links.vue'), meta: { title: '友链' } },
```

**③ 加导航** `src/layouts/DefaultLayout.vue`

```vue
<RouterLink to="/links" class="nav-link">友链</RouterLink>
```

**④ 封装 api**（可选，接口多时建议）

```js
// src/api/link.js
import request from './request'
export function fetchLinks() { return request.get('/links') }
```

## 二、请求封装约定（`src/api/request.js`）

| 约定 | 说明 |
|---|---|
| `baseURL: '/api/v1'` | 开发期由 Vite proxy 转发，生产期由 Nginx 转发 |
| 请求拦截器 | 自动带 `Authorization: Bearer <token>` |
| 响应拦截器（成功） | `code === 0` 时**直接返回 `data`**，页面里拿到的是业务数据 |
| 响应拦截器（失败） | 统一 `ElMessage.error`，并 `reject` 让调用方能感知 |
| 401 | 自动清 token + 提示重新登录 |
| 403 | 提示「无权限」 |

**所以页面里这样写就行：**

```js
const data = await fetchArticles({ page: 1 })
articles.value = data.list        // 不是 data.data.list
```

## 三、路由与守卫

```js
// 布局作为父路由
{
  path: '/',
  component: DefaultLayout,
  children: [ home, articleDetail, archive, tags, about ],
},
{
  path: '/admin',
  component: AdminLayout,
  meta: { requiresAuth: true },    // 整组需要登录
  children: [ articles, articleNew, articleEdit, comments ],
},
```

```js
router.beforeEach((to) => {
  if (!to.meta.requiresAuth) return true
  if (localStorage.getItem('token')) return true
  return { name: 'admin-login', query: { redirect: to.fullPath } }
})
```

**注意**：前端守卫只是体验优化，**真正的安全在后端**。改 localStorage 就能绕过。

## 四、登录态（`src/stores/user.js`）

```js
const userStore = useUserStore()

await userStore.login('admin', '123456')   // 存 token + user 到 localStorage 和 store
userStore.isLoggedIn                        // computed
```

## 五、Markdown 渲染（`src/utils/markdown.js`）

```js
import { renderMarkdown } from '../utils/markdown'

const html = renderMarkdown(md)
```

```vue
<div class="markdown-body" v-html="html"></div>
```

**三条铁律**
1. **`v-html` 的内容必须过 DOMPurify**（`renderMarkdown` 内部已经做了），否则可注入脚本偷 token
2. 代码高亮要 `langPrefix: 'hljs language-'`，并在页面里 `import 'highlight.js/styles/github.css'`
3. 不要 `import hljs from 'highlight.js'`（全量 1MB），只注册用到的语言

## 六、Element Plus 用法要点

| 场景 | 写法 |
|---|---|
| 消息提示 | `import { ElMessage } from 'element-plus'; ElMessage.success('ok')` |
| 确认框 | `await ElMessageBox.confirm('确定？','提示',{type:'warning'})`，取消会 reject，**必须 try/catch** |
| 表格 | `<el-table :data="list" v-loading="loading">` |
| 表单校验 | `el-form` + `rules`，或后端返回错误信息直接弹 |
| 分页 | `v-model:current-page="page"` + `@current-change="load"` |
| 上传 | `el-upload` + `:before-upload` 自己发请求（返回 `false` 阻止默认上传） |

## 七、前端常见坑

| 坑 | 症状 | 解法 |
|---|---|---|
| `v-html` 未净化 | 有 XSS 风险 | 走 `renderMarkdown` |
| 筛选后没回第 1 页 | 页面空白/没数据 | 改筛选时 `page.value = 1` |
| `loading` 没在 finally 关 | 报错后一直转圈 | `try/finally` |
| 刷新后 404（生产） | Nginx 没配 history 回退 | `try_files $uri $uri/ /index.html` |
| 图片 404 | 存的是 `/uploads/xxx` 但代理没配 | 代理 `/uploads` 或让返回完整 URL |
| 打包体积爆炸 | 全量引入组件库/高亮库 | 按需引入 |
| 改了代码页面没变 | Vite HMR 失效 / 看的是旧标签 | 硬刷新，或检查 dev server 是否还在 |

## 八、调试三板斧

1. **Network 面板**：看真实状态码、请求头（有没有带 token）、响应体
2. **Console**：看报错堆栈，注意 `[Vue warn]` 往往指向真正的问题
3. **Vue DevTools**：看组件的 `props` / `ref` 当前值，比 `console.log` 精准

排查顺序：**先确认后端对不对（curl），再确认网络对不对（Network），最后看组件逻辑。**
