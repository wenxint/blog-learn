## 项目速览

一个从零手写的前后端分离博客：**Go + Vue3**，没有用现成博客系统。

| 维度 | 实际情况 |
|---|---|
| 后端 | Go 1.26 · Gin · GORM · MySQL 8.4 · JWT · bcrypt |
| 前端 | Vue 3 · Vite · Vue Router · Pinia · Element Plus |
| 接口 | 34 个（公开 8 / 认证 4 / 后台 15 / 诊断 4，其余为静态资源） |
| 数据表 | 6 张（users / categories / tags / articles / article_tags / comments） |
| 单测 | 24 个（config 7 / hash 6 / jwt 6 / ratelimit 5） |
| 页面 | 前台 6 页 + 后台 5 页 |
| 部署 | 单机 Nginx + systemd + 交叉编译单文件二进制 |
| 文章系列 | 13 篇，后端 6 篇 + 部署 3 篇，全部带讲解图 |

## 文章是怎么进到站点里的

文章不是直接写进数据库的，源文件在 `docs/articles/`，用脚本导入：

```bash
# 1. 写文章：docs/articles/xx-名字.md，开头带 frontmatter
# 2. 画图：frontend/public/diagrams/名字.svg
# 3. 确认后端在跑，然后导入（按标题幂等：存在就更新，不存在才创建）
python3 scripts/import_articles.py --password 你的后台密码

# 只看会做什么，不写库
python3 scripts/import_articles.py --password 你的后台密码 --dry-run
```

frontmatter 的字段：

```yaml
---
title: 标题
summary: 一句话摘要（会显示在列表页）
category: 建站记
tags: 架构, 后端
status: 1      # 1 发布，0 草稿
is_top: 0      # 1 置顶
---
```

图片写在正文里，路径用站点的绝对路径：

```markdown
![一句结论式说明，会渲染成图注](/diagrams/xxx.svg)
```

## 文档约定

1. **as-built 优先**：文档描述代码当前真实状态，不写「计划中」冒充「已完成」；未做的写在「已知限制」。
2. **数字要有出处**：接口数、表数、单测数、体积，都以代码或实测为准；没有实测就写「约」或不写。
3. **迁移只加不改**：`backend/migrations/` 下执行过的 SQL 永久冻结。
4. **文章与代码同步**：改动了文章里引用的行为，要顺手改文章；文章是代码的另一种注释。
5. **图不是装饰**：每张图都要能独立回答一个问题，`alt` 就是它的结论。
