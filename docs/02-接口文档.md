# 接口文档

> Base URL：`http://127.0.0.1:8090/api/v1`
> 所有接口返回统一结构：`{ code, message, data }`，`code === 0` 表示成功。
> 需要登录的接口加请求头：`Authorization: Bearer <token>`。

**快速准备**

```bash
BASE=http://127.0.0.1:8090/api/v1
TOKEN=$(curl -s -X POST $BASE/auth/login -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}' | python3 -c "import sys,json;print(json.load(sys.stdin)['data']['token'])")
```

## 一、公开接口

### 健康检查

```bash
curl -s $BASE/ping
```

```json
{ "code": 0, "message": "ok", "data": { "pong": true } }
```

### 文章列表

```bash
curl -s "$BASE/articles?page=1&page_size=10&keyword=Go&category_id=1&tag_id=2&month=2026-11"
```

| 参数 | 类型 | 说明 |
|---|---|---|
| page | int | 页码，默认 1 |
| page_size | int | 每页条数，默认 20，上限 100 |
| keyword | string | 标题模糊搜索，最长 50 |
| order | string | `asc` 按发布时间正序（系列阅读顺序）；不传=最新在前 |
| category_id | int | 按分类筛选 |
| tag_id | int | 按标签筛选 |
| month | string | 按发布月份筛选，格式 `2026-11` |

```json

  "message": "ok",
  "data": {
    "list": [
      {
        "id": 1,
        "title": "Go 从零开始：第一个 HTTP 服务",
        "summary": "用标准库 net/http 起一个服务…",
        "cover": "",
        "status": 1,
        "is_top": 1,
        "view_count": 320,
        "like_count": 12,
        "author_id": 1,
        "author": { "id": 1, "username": "admin", "nickname": "陶文鑫", "role": "admin" },
        "category_id": 1,
        "category": { "id": 1, "name": "技术笔记", "slug": "tech" },
        "tags": [{ "id": 1, "name": "Go", "slug": "go" }],

```

> 列表不返回 `content`（正文 `longtext` 太大），也不返回 `deleted_at`。

- 不存在返回 `404 / 10004`

### 发表评论

```bash
curl -s -X POST $BASE/articles/1/comments \
  -H "Content-Type: application/json" \
  -d '{"nickname":"访客","email":"a@b.com","content":"写得不错","parent_id":0}'
```

```json
{
  "code": 0,
  "data": {
    "comment": { "id": 6, "article_id": 1, "status": 0, "nickname": "访客", "content": "写得不错" },
    "message": "评论已提交，等待管理员审核后展示"
  }
}
```

| 错误 | 说明 |
|---|---|
| 400 | 昵称/内容为空、超长、邮箱格式错、回复的评论不属于本文、**回复的回复（超过两级）** |
| 404 | 文章不存在或未发布 |
| 429 | 同一 IP 发得太频繁（默认 60 秒 3 条），消息里会给出还需等待的秒数 |

## 二、认证接口

### 注册

```bash
curl -s -X POST $BASE/auth/register -H "Content-Type: application/json" \
  -d '{"username":"reader01","password":"reader123","nickname":"路人甲","email":"r@example.com"}'
```

- 用户名：3~50 位字母/数字/下划线
- 密码：6~72 字节（bcrypt 上限 72）
- 角色固定 `author`
- 返回体**不含** `password_hash`

| 错误 | 说明 |
|---|---|
| 400 | 用户名格式错、密码太短、邮箱格式错 |
| 409 | 用户名已存在 |

### 登录

```bash
curl -s -X POST $BASE/auth/login -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'
```

```json
{
  "code": 0,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs…",
    "expires_at": "2026-11-14T14:07:13+08:00",
    "user": { "id": 1, "username": "admin", "nickname": "陶文鑫", "role": "admin" }
  }
}
```

| 错误 | 说明 |
|---|---|
| 401 | 用户名或密码错误（**两种情况返回同样的消息**，防用户名枚举） |
| 401 | 账号已禁用 |

### 当前用户资料

```bash
curl -s -H "Authorization: Bearer $TOKEN" $BASE/auth/profile
```

### 修改密码

```bash
curl -s -X PUT -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  $BASE/auth/password -d '{"old_password":"123456","new_password":"newpass123"}'
```

| 错误 | 说明 |
|---|---|
| 400 | 原密码错误 / 新密码太短 / 新旧密码相同 |

## 三、后台接口（需 token）

### 文章

```bash
# 列表（含草稿）；status 可选：0 草稿 / 1 已发布 / 不传=全部
curl -s -H "Authorization: Bearer $TOKEN" "$BASE/admin/articles?page=1&status=0"

# 详情（草稿也能看，用于编辑回填）
curl -s -H "Authorization: Bearer $TOKEN" $BASE/admin/articles/5

# 新建
curl -s -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  $BASE/admin/articles -d '{
    "title":"我的第一篇",
    "summary":"摘要",
    "content":"# 标题\n\n正文",
    "status":1,
    "is_top":0,
    "category_id":1,
    "tag_ids":[1,2]
  }'

# 编辑（全量覆盖，未传字段会被清空）
curl -s -X PUT -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  $BASE/admin/articles/6 -d '{"title":"改过了","content":"x","status":0,"tag_ids":[]}'

# 删除（软删除，需 admin 角色）
curl -s -X DELETE -H "Authorization: Bearer $TOKEN" $BASE/admin/articles/6
```

**请求体字段说明**

| 字段 | 必填 | 说明 |
|---|---|---|
| title | ✅ | 最长 200 |
| content | ✅ | Markdown 原文 |
| summary | | 最长 500 |
| cover | | 封面图 URL |
| status | | 0 草稿 / 1 发布，默认 0 |
| is_top | | 0 普通 / 1 置顶 |
| category_id | | 0 表示未分类 |
| tag_ids | | 标签 id 数组，**全量替换** |
| author_id | | **会被 token 里的用户覆盖**，传了也没用 |

**行为说明**
- 草稿→发布时自动补 `published_at`；发布→草稿时清空
- 标签全量替换在事务里完成（先删旧关联再插新的）
- 删除是软删除：数据还在，`deleted_at` 有值

### 分类（admin）

```bash
curl -s -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  $BASE/admin/categories -d '{"name":"新分类","slug":"new-cat","description":"","sort":9}'

curl -s -X PUT -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  $BASE/admin/categories/3 -d '{"name":"改个名","slug":"new-cat","sort":8}'

curl -s -X DELETE -H "Authorization: Bearer $TOKEN" $BASE/admin/categories/3
```

- 名称或 slug 重复 → `409`
- **分类下还有文章 → `409`**，提示「该分类下还有 N 篇文章」

### 标签

```bash
curl -s -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  $BASE/admin/tags -d '{"name":"新标签","slug":"new-tag"}'

curl -s -X DELETE -H "Authorization: Bearer $TOKEN" $BASE/admin/tags/5
```

- 新建/编辑：登录即可
- 删除：需 admin，会**同时清理 `article_tags`**（事务）

### 评论审核（admin）

```bash
# 列表：status=0 待审核 / 1 已通过（默认 0）
curl -s -H "Authorization: Bearer $TOKEN" "$BASE/admin/comments?status=0&page=1"
```

```json
{
  "code": 0,
  "data": {
    "list": [
      { "id": 5, "article_id": 2, "nickname": "待审核的评论", "content": "…", "ip": "127.0.0.1", "status": 0 }
    ],
    "total": 1,
    "page": 1,
    "page_size": 20,
    "pending_count": 1
  }
}
```

> 后台 DTO 带 `ip`（前台接口不带，这是有意的字段隔离）。

```bash
# 通过 / 打回
curl -s -X PUT -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  $BASE/admin/comments/5/status -d '{"status":1}'

# 删除（连带删除其回复）
curl -s -X DELETE -H "Authorization: Bearer $TOKEN" $BASE/admin/comments/5
```

### 图片上传

```bash
curl -s -X POST -H "Authorization: Bearer $TOKEN" -F "file=@/path/to/pic.png" $BASE/admin/upload
```

```json
{
  "code": 0,
  "data": {
    "url": "/uploads/2026/11/f3179b42636994bb.png",
    "file_name": "f3179b42636994bb.png",
    "size": 165,
    "mime": "image/png"
  }
}
```

| 限制 | 说明 |
|---|---|
| 类型 | jpg / png / gif / webp（**按文件内容判断**，不看扩展名） |
| 大小 | ≤ `UPLOAD_MAX_MB`（默认 5MB） |
| 文件名 | 服务端随机生成，不用用户文件名 |
| 访问 | `GET /uploads/2026/11/xxx.png` |

错误示例：

```json
{ "code": 10001, "message": "参数不合法: 只允许 jpg/png/gif/webp 图片，识别到的类型是 text/plain" }
```

## 四、诊断接口（仅 dev）

```bash
curl -s $BASE/debug/db          # 数据库版本、表、连接池状态、ping 耗时
curl -s $BASE/debug/models      # 模型与表结构一致性检查
curl -s $BASE/debug/tx-rollback # 事务回滚演示（rolled_back 应为 true）
curl -s $BASE/debug/panic       # 故意 panic，验证 Recovery
curl -s $BASE/debug/slow        # 3 秒慢请求，验证优雅关闭排空
```

`APP_ENV=prod` 时这些路由**不会注册**（启动日志里看不到）。

## 五、错误响应速查

| 场景 | HTTP | code |
|---|---|---|
| 参数校验失败 | 400 | 10001 |
| 未带 token / token 无效或过期 | 401 | 10002 |
| 非 admin 调用 admin 接口 | 403 | 10003 |
| 资源不存在（含草稿、不存在路由） | 404 | 10004 |
| 重名 / 分类下有文章 | 409 | 10005 |
| 服务器内部错误 | 500 | 10006 |
| 评论发得太频繁（限流） | 429 | 10007 |

**所有 4xx/5xx 的响应体结构一致**（包括 404 未匹配路由），前端拦截器可以统一处理。
