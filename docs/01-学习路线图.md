# 学习路线图（20 课）

> 模式：**我讲解 + 给代码块，你自己敲，我在你卡住时 review**
> 每课约 40~90 分钟。每课都有「学什么 / 你会敲什么 / 验收标准」，验收过了再进下一课。

---

## 阶段 A · 地基（第 1~3 课）

### 第 1 课：环境 + 项目骨架 + 第一个 Go 服务
**学什么**
- HTTP 请求/响应到底长什么样（不看框架，先用标准库 `net/http`）
- Go 的最小程序结构：`package`、`import`、`func main`
- 端口、监听、路由注册在底层是什么

**你会敲**
- `blog/backend` 目录结构、`go mod init`
- `main.go`：起一个 `:8090` 服务，两个路由 `/ping` 和 `/hello`
- `.gitignore`、`git init`

**验收**
```bash
curl http://127.0.0.1:8090/api/v1/ping
# {"code":0,"message":"ok","data":{"pong":true}}
```

---

### 第 2 课：装 MySQL + SQL 基础
**学什么**
- 关系型数据库是什么，表/行/列/主键/外键
- 建库建表、`INSERT/SELECT/UPDATE/DELETE`
- 字符集为什么必须是 `utf8mb4`
- 为什么不用 root 账号连应用

**你会敲**
- `brew install mysql@8.4`、启动服务、设 root 密码
- 建 `blog` 库 + 专用账号 `blog`
- 手写 `users`、`articles` 两张表的 DDL
- 10 条练习 SQL（自己写，我出题 + 对答案）

**验收**
```bash
mysql -u blog -p blog -e "SHOW TABLES; SELECT * FROM users;"
```

---

### 第 3 课：Gin 上手 + 统一响应
**学什么**
- Gin 的 `gin.Context`、路由分组、参数绑定、`c.JSON`
- 中间件是什么（洋葱模型），为什么日志/CORS/Recover 要做成中间件
- 统一响应体 + 业务错误码的设计

**你会敲**
- `go get github.com/gin-gonic/gin`
- `internal/pkg/response` 统一响应包
- `internal/router/router.go` 路由分组 `/api/v1`
- 三个中间件：日志、Recover、CORS

**验收**：浏览器直接访问 `:8090` 也能返回 JSON；前端 `:5173` 跨域请求不报 CORS 错

---

## 阶段 B · 数据层（第 4~7 课）

### 第 4 课：配置 + 数据库连接
**学什么**
- `.env` 与 `godotenv`，配置为什么不能硬编码
- `database/sql` 连接池：`MaxOpenConns` / `MaxIdleConns` / `ConnMaxLifetime`
- DSN 的每个参数是什么意思

**你会敲**
- `internal/config/config.go`
- `internal/database/mysql.go`：连库 + Ping + 连接池
- `main.go` 里接上，启动时打印「数据库连接成功」

**验收**：日志出现数据库连接成功；把密码改错会明确报错退出（不是静默失败）

---

### 第 5 课：GORM 建表 + 第一个 Model
**学什么**
- ORM 是什么、解决什么问题、什么时候不该用
- GORM tag：`primaryKey` / `size` / `index` / `uniqueIndex` / `default`
- `AutoMigrate` 干了什么，为什么不建议生产直接用

**你会敲**
- `internal/model/user.go` + `article.go`
- `AutoMigrate` 建表，去 MySQL 里 `DESC users;` 看字段

**验收**：`SHOW CREATE TABLE articles\G` 能看到索引和 `utf8mb4`

---

### 第 6 课：CRUD + 事务
**学什么**
- GORM 的 `Create/First/Find/Updates/Delete`
- 软删除（`deleted_at`）与硬删除的区别
- 事务：`db.Transaction()`，什么场景必须用（文章 + 标签同时写）

**你会敲**
- 一个一次性脚本 `cmd/seed/main.go`：插入 3 个分类、10 篇文章
- 手写一次事务：新建文章同时写 `article_tags`

**验收**：MySQL 里查到 10 条文章，`article_tags` 关系正确

---

### 第 7 课：分层重构（handler / service / repository）
**学什么**
- 为什么不能把 SQL 和 HTTP 写在一个函数里
- 接口（interface）在 Go 里怎么做依赖倒置
- 构造函数注入 vs 全局变量

**你会敲**
- 把第 6 课的逻辑拆成 `article_repo.go` / `article_service.go` / `article_handler.go`
- `main.go` 里手工装配

**验收**：`GET /api/v1/articles` 从真实数据库返回分页列表

---

## 阶段 C · 认证与权限（第 8~10 课）

### 第 8 课：用户注册与密码哈希
**学什么**
- 为什么数据库不能存明文密码
- bcrypt 的盐、成本因子（cost）
- 参数校验：用户名长度、密码强度、邮箱格式

**你会敲**
- `pkg/hash`：`HashPassword` / `CheckPassword`
- 注册接口 `POST /api/v1/auth/register`（或直接用 seed 造管理员）

**验收**：数据库里 `password_hash` 是 `$2a$10$...` 形式；同一个密码两次哈希结果不同

---

### 第 9 课：登录 + JWT 签发
**学什么**
- 登录流程：查用户 → 校验密码 → 签发 token
- JWT 三段结构（Header.Payload.Signature）分别是什么，为什么能防篡改
- 为什么用 HS256、密钥泄露会怎样

**你会敲**
- `pkg/jwt`：`GenerateToken` / `ParseToken`
- `POST /api/v1/auth/login`

**验收**：`curl` 登录拿到 token，粘到 jwt.io 能看到 payload

---

### 第 10 课：鉴权中间件 + 权限控制
**学什么**
- 中间件里怎么从 Header 取 token、放用户信息进 context
- `c.Set/c.Get` 的坑（类型断言）
- 401 与 403 的区别；角色权限怎么做

**你会敲**
- `middleware/jwt.go`：`AuthRequired()`、`AdminOnly()`
- 一个受保护接口 `GET /api/v1/auth/profile`

**验收**：不带 token → 401；带 author 的 token 访问 admin 接口 → 403

---

## 阶段 D · 业务 API（第 11~15 课）

### 第 11 课：文章列表（分页 / 筛选 / 搜索）
**学什么**
- 分页 SQL：`LIMIT/OFFSET` 与 `COUNT(*)`
- 动态拼接查询条件（GORM `db.Where` 链式）
- 搜索用 `LIKE` 的性能问题与优化方向

**你会敲**：`ArticleService.List` + `ArticleRepository.List` + handler

**验收**：`/api/v1/articles?page=2&page_size=5&keyword=Go` 结果正确，`total` 准确

---

### 第 12 课：文章详情 + 分类 + 标签
**学什么**
- 预加载 `Preload`（N+1 查询问题）
- 阅读数自增的并发安全（`gorm.Expr`）
- 多对多关系的查询与序列化

**你会敲**：详情、分类列表（含 count）、标签列表接口

**验收**：详情返回作者、分类、标签嵌套对象；刷新两次 `view_count` +2

---

### 第 13 课：文章增删改（Markdown + 标签同步）
**学什么**
- 入参 DTO 与 Model 分离（为什么不让前端直接传 Model）
- 更新时标签关联的全量替换
- 草稿 / 发布 状态流转

**你会敲**：`POST/PUT/DELETE /api/v1/admin/articles`

**验收**：新增文章后前台立刻能搜到；删文章后关联标签表也清干净

---

### 第 14 课：评论（楼中楼 + 审核）
**学什么**
- 树形结构怎么在扁平表里存（`parent_id`）
- 一次查询组装二级树（避免递归查库）
- 简单防刷：同 IP 频率限制（内存计数即可）

**你会敲**：评论列表（组装树）、发表评论、后台审核

**验收**：一级评论下能正确挂出回复；未审核评论前台不可见

---

### 第 15 课：图片上传 + 静态资源
**学什么**
- `multipart/form-data` 与 `FormFile`
- 文件大小限制、类型白名单、随机文件名（防覆盖 + 防路径穿越）
- Gin `Static` 暴露上传目录

**你会敲**：`POST /api/v1/admin/upload`、`GET /uploads/:file`

**验收**：上传 png 拿到可访问 URL；传 `.exe` 被拒

---

**你会敲**：`router/index.js`、`layouts/DefaultLayout.vue`、`views/home/Home.vue`

## 阶段 F · 收尾与进阶（第 20 课）

### 第 20 课：部署 + 性能与安全清单
**学什么**
- `go build` 交叉编译、单文件部署
- 前端 `pnpm build` 产物 + Nginx 反向代理
- 慢查询与索引、`EXPLAIN` 怎么看
- 上线前检查清单：CORS 白名单、JWT 密钥、上传目录权限、SQL 注入、XSS

**你会敲**：`Makefile`、`deploy/nginx.conf`、README 运行说明

**验收**：一条命令构建前后端；README 里从零到跑通不超过 5 步

---

## 学习原则

1. **先跑通，再理解，最后优化** —— 每课都先让代码动起来
2. **报错不要猜** —— 把完整报错贴给我，我讲它为什么这么说
3. **每课留一个「如果你来改」的小任务** —— 检验是否真懂
4. **不懂就问，别硬撑** —— 一个概念卡住，后面全是迷雾
